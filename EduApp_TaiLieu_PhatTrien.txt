(RAG)Khái niệm RAG đơn giảnRAG (Retrieval-Augmented Generation) cho phép AI trả lời dựa trên nội dung tài liệu cụ thể thay vì kiến thức chung. Cách implement đơn giản nhất:Tìm các chunk liên quan đến câu hỏi (keyword matching hoặc semantic search)Ghép các chunk đó làm context cho GeminiGemini trả lời dựa trên context, không sáng tạo ngoài tài liệuCloud Function — Q&Aexports.askQuestion = functions.https.onCall(async (data, context) => {  const { question, documentId, conversationHistory = [] } = data;  // Bước 1: Tìm chunks liên quan (keyword search đơn giản)  const chunks = await getDocumentChunks(documentId);  const relevant = findRelevantChunks(question, chunks, 3);  const contextText = relevant.map(c => c.text).join('\n\n');  // Bước 2: Build conversation history  const history = conversationHistory.slice(-6)  // giữ 6 turn gần nhất    .map(m => `${m.role}: ${m.content}`).join('\n');  const prompt = `Bạn là trợ lý học tập. Chỉ trả lời dựa trên tài liệu được cung cấp.Nếu không có đủ thông tin, hãy nói rõ.TÀI LIỆU:${contextText}LỊCH SỬ HỘI THOẠI:${history}CÂU HỎI: ${question}Trả lời ngắn gọn, chính xác. Nếu trích dẫn, ghi rõ nguồn.`;  const answer = await callGemini(prompt);  return { answer, sourcesUsed: relevant.map(c => c.index) };});Hàm tìm Chunk liên quanfunction findRelevantChunks(question, chunks, topK = 3) {  const qWords = question.toLowerCase().split(' ')    .filter(w => w.length > 3);  // bỏ stop words ngắn  return chunks    .map(chunk => ({      ...chunk,      score: qWords.filter(w => chunk.text.toLowerCase().includes(w)).length    }))    .sort((a, b) => b.score - a.score)    .slice(0, topK);}Để tìm kiếm chính xác hơn, có thể nâng cấp lên semantic search bằng Gemini Embedding API (miễn phí) — tính cosine similarity giữa embedding của câu hỏi và từng chunk. doc.data().count : 0;    if (count >= DAILY_LIMITS[action]) {      throw new functions.https.HttpsError(        'resource-exhausted',        `Đã đạt giới hạn ${DAILY_LIMITS[action]} lần/ngày`      );    }    t.set(ref, { count: count + 1 }, { merge: true });  });}7.2 Caching Kết Quả AICache quiz đã tạo để không phải gọi lại Gemini nếu người dùng tạo quiz từ cùng tài liệu:// Trước khi gọi Gemini, kiểm tra cacheconst cacheKey = `quiz_${documentId}_${numQuestions}_${difficulty}`;const cached = await db.collection('quizCache').doc(cacheKey).get();if (cached.exists && isNotExpired(cached.data().createdAt, 24)) {  return { questions: cached.data().questions, fromCache: true };}// Gọi Gemini và lưu cacheconst questions = await generateWithGemini(prompt);await db.collection('quizCache').doc(cacheKey).set({  questions, createdAt: admin.firestore.FieldValue.serverTimestamp()});7.3 Tối Ưu Token GeminiChiến lượcTiết kiệm ước tínhChỉ gửi 2-3 chunk liên quan thay vì toàn bộ tài liệu60-80% token/requestCache quiz đã tạo trong 24hLoại bỏ 70% duplicate callsGiới hạn conversation history Q&A (6 turns gần nhất)40% token/sessionDùng Gemini 1.5 Flash thay vì ProChi phí thấp hơn 10x khi vượt free tierCompress prompt — bỏ khoảng trắng thừa trong text5-10% token8.
